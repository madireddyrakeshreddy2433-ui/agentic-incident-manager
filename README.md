# Agentic Incident Manager

Enterprise Agentic AI learning project focused on safe and intelligent Major Incident Management.

## Project Goal

Build an Agentic AI system capable of:

- Investigating incidents using live operational data
- Retrieving relevant SOPs, RCAs and historical incidents
- Correlating evidence using an LLM
- Recommending safe remediation actions
- Requesting human approval for high-risk actions
- Executing approved deterministic workflows
- Verifying actual service recovery
- Communicating incident status to stakeholders

## Core Architecture

The solution will combine:

- LLM reasoning
- RAG
- State management
- Enterprise tools and APIs
- Human-in-the-loop approvals
- Power Automate
- Guardrails and policy validation
